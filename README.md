# 📡 處置股雷達(個人用)

每個交易日台灣時間 18:40 自動執行:
1. 抓證交所/櫃買中心的注意股、快進處置名單、處置股
2. 整理成「快進處置 / 快出關 / 剛出關 / 處置中 / 今日注意」
3. 更新手機 App(GitHub Pages)並發 LINE 推播

## 檔案說明
| 檔案 | 用途 |
|---|---|
| `fetch_data.py` | 主程式。最上面 ★★★ 設定區可改觀察名單、天數等 |
| `.github/workflows/daily.yml` | 每天自動執行的排程 |
| `docs/index.html` | 手機 App 畫面 |
| `docs/data.json` | 每天更新的資料(程式自動產生) |
| `data/history.json` | 累積的處置紀錄(程式自動產生) |
| `tests/demo/` | 測試用的範例資料 |

## 本機測試(不連網路、不發 LINE)
```
DEMO_DIR=tests/demo DEMO_TODAY=2026-11-23 python fetch_data.py
```

## 已知限制(第一版)
- 「快出關/剛出關」的交易日只排除週末,遇到國定假日會差一天。
- 「快進處置」目前只有上市股票(證交所官方名單);上櫃只有處置股。
- 處置中名單從開始使用那天起累積,第一週可能不完整。
- 個股期標記是自動抓期交所名單,抓不到時請在設定區 `EXTRA_SSF_CODES` 自己補。
